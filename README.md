# Student_mngmnt_system_csv_saving_n_loading
simple csv saving, csv reading and input validation for integers

A console-based Student Record Management System built with C++ as part of my programming self-learning journey.

Features

- Add student records
- View existing records
- Automatically generate student IDs
- Save student records to a CSV file
- Load saved records when the program starts

Concepts Practised

- C++ functions and classes
- STL vectors and references
- File handling with "ifstream" and "ofstream"
- CSV data parsing and persistence
- Organizing code across ".cpp" and ".hpp" files

Note: The program uses "student_record.csv" to store records. Keep the CSV file in the appropriate working directory when running the program so saved records can be loaded.

About

This project was created to practise applying fundamental C++ concepts in a small, practical application. It is an ongoing learning project, with further improvements possible as I develop my programming skills.
